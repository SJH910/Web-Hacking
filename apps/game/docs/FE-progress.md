## 실행 매뉴얼
```sh
cd /Users/jisu/Documents/Web-Hacking/apps/game
npm run build
cd ../../tools/vulnscan
python3 scanner.py --port 8900
```
- 통합 화면: http://127.0.0.1:8900/#game
- 기존 데모: http://127.0.0.1:8900/game/
- 새 플레이: http://127.0.0.1:8900/game/play/
- 기존 데모 상단의 등반 시작으로 새 플레이에 진입한다.
- 현재 scanner에는 /api/game API가 없다. 새 등반을 누르면 연결 안내가 나오는 것이 현재 상태다. API 경로·응답은 FE 제안이므로 B 담당과 맞춰야 한다.
- Next dev 단독 포트에서는 같은 origin의 /api/game 서버 또는 프록시가 추가로 필요하다.

## 검증 결과
- npm run typecheck, npm run build 통과. /play 정적 출력 확인.
- node --test tests/*.test.mjs: 17개 통과. 데이터 범위·저장 손상·API 실패·판정 잠금·터미널/선택형·통과/10층·폴백 힌트·빈 랭킹 포함.
- python3 -m unittest test_game_routes.py: 7개 통과.
- 실제 브라우저에서 초기 화면 및 새 등반 클릭 후 API 미연결 안내 확인.
- 390px 초기/오류 화면에서 가로 넘침 없음(뷰포트 390, 문서 너비 375). 관측한 콘솔 오류 없음.
- 미검증: 실제 API의 탐색→3단 판정→통과, 힌트 품질, 서버 저장/랭킹, 19문제/10층, 전체 키보드·스크린리더 및 다른 해상도.
- Node 테스트에서 기존 패키지의 MODULE_TYPELESS_PACKAGE_JSON 경고 발생. 테스트 실패는 아님.
