## 작업 내용
명령 입력·출력 이력·빈 상태·실행 중 중복 요청 차단을 추가했다. 출력은 React 텍스트로 표시하며 임의 셸 실행은 없다.

## 사용 매뉴얼
등반 시작 후 터미널형 문제에서 help를 입력한다. 서버가 알려 준 명령을 입력하면 출력과 발견한 증거가 갱신된다.

## 동작 설명
commands 요청의 output과 state.evidence를 표시한다. 허용 명령 판정은 서버 책임이며 FE에 명령 스크립트를 넣지 않았다.
