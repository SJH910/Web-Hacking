## 1. 결과 요약

problem-pool.md §2 규칙대로 시드 결정적으로 10문제를 고른다. 같은 시드는 항상 같은 순서이고 문제는 중복되지 않는다.

## 2. 상세

- [game_order.py](../../../tools/vulnscan/game_order.py): 1~3층 쉬움 3 → 4~8층 무작위 5 → 9~10층 어려움 2(모자라면 보통으로 보충).
- 객관식 5개 초과 시 뒤 층부터 남은 터미널로 교체한다. 도입·클라이맥스 층은 같은 난이도를 우선하고, 그래도 넘으면 난이도 제한을 풀어 교체한다.
- 시드는 등반 생성 시 서버가 만들어 저장한다(이어하기·랭킹 공정성).

## 3. 검증

`test_game_order.py`: 풀 최소 조건, 200개 시드의 결정성·중복 없음·난이도 곡선, 객관식 상한(터미널 6·객관식 8 합성 풀), 작은 풀.

## 4. 남은 것·참고

- 9~10층의 어려움 2개를 보장하려고 **클라이맥스 문제를 중반 추첨보다 먼저 확보**한다(문서 순서와 다르지만 결과 규칙은 같다). 객관식 교체 2차는 난이도를 무시하므로 풀에 터미널이 부족하면 곡선이 깨질 수 있다.
- 풀이 10개 미만이면 그만큼의 층만 만든다.
