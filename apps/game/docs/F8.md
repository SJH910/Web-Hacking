## 작업 내용
버전이 있는 localStorage 저장과 이어하기·새 등반 확인을 추가했다. 손상·저장 제한 오류를 안내한다.

## 사용 매뉴얼
등반 시작/행동 후 자동 저장된다. 재접속 시 저장한 등반 이어하기를 누른다. 새 등반은 기존 기록이 있을 때 확인 단계를 거친다.

## 동작 설명
tower.run.v1에 version/runId만 저장한다. 진행·시드·점수는 GET으로 서버에서 복원한다. 원문 localStorage 단독 MVP와 달리 서버 재검증 방식이므로 B5에 의존한다.
