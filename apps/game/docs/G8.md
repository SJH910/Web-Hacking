## 풀 현황

- 터미널 **14** / 객관식 **5** · 쉬움 6 / 보통 8 / **어려움 5**
- OWASP **A01~A10 전 항목** 커버
- **결론 다양화:** **취약 13** + **양호 5**(quiet-vault·strong-gate·archive·login·greenhouse) + **증거 부족 1**(faint-steps) → "항상 취약" 패턴 방지
  - 판정 UI는 3지선다(양호/취약/증거 부족). "정상"은 양호에 흡수하되 **해설에서 방어 작동형 / 오판 방지형 구분** (상세: [problem-pool.md](../problem-pool.md) §5)
  - login 결론은 원본 `scenarios.ts`(인증 성공·관리자 403) 기준 **양호**로 확정
- **대조쌍:** night-log(취약) ↔ strong-gate(양호) — 같은 로그인 소재, 잠금·기록 유무로 결론 갈림

## 설계 포인트

- 각 문제: 명령·출력 / 증거 / 3단 판정(함정 보기) / 라온 틀린 말 + 힌트 / flag
- **라온 함정**을 매 문제 분류·판정 오답과 연결(증거로 반박하게)
- **needs_review 문제**로 "증거 불충분 시 단정 금지" 학습
