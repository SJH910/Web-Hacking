## 결과 요약

풀을 **목표 12~15의 상단(15문제)**까지 채웠다. 배치1 +6, 배치2 +5.
- **배치1(6):** old-lock·whisper·plaintext·twisted·quiet-vault(양호)·open-window
- **배치2(5):** weak-otp(A06)·integrity-box(A08)·faint-steps(A09 증거부족)·strong-gate(A07 양호)·mirror-room(A05 XSS 어려움)

| id | 제목 | type | 난이도 | OWASP | 결론 |
|---|---|---|---|---|---|
| old-lock | 낡은 자물쇠 | terminal | 쉬움 | A03 | 취약 |
| whisper | 속삭이는 오류 | terminal | 쉬움 | A10 | 취약 |
| plaintext | 평문의 문 | terminal | 보통 | A04 | 취약 |
| twisted | 뒤바뀐 질문 | terminal | 보통 | A05 | 취약 |
| quiet-vault | 조용한 금고 | terminal | 쉬움 | A02 | **양호** |
| open-window | 열린 창문 | choice | 보통 | A01 | 취약 |

## 풀 현황 (총 19)

- 터미널 **14** / 객관식 **5** · 쉬움 6 / 보통 8 / **어려움 5**
- **배치3(어려움 4):** returned-letter(SSRF)·two-faced-token(미서명 토큰)·slow-confession(시간 기반 블라인드 SQLi)·deceptive-door(겉은 양호·속은 취약)
- OWASP **A01~A10 전 항목** 커버
- **결론 다양화:** 취약 다수 + **양호 2**(quiet-vault·strong-gate) + **정상 1**(archive) + **증거 부족 1**(faint-steps) → "항상 취약" 패턴 방지
- **대조쌍:** night-log(취약) ↔ strong-gate(양호) — 같은 로그인 소재, 잠금·기록 유무로 결론 갈림

## 설계 포인트
