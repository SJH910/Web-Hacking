## 결과 요약

선형 10층 + **성과 기반 엔딩 분기**를 확정했다. 재시도형(실패 없음)이라 분기는 "얼마나·어떻게 올랐나"로 발현.

## 엔딩 분기 (두 축 · 6엔딩)

- **신뢰도:** 높음 ≥80 / 중간 40~79 / 낮음 <40
- **정확도:** 정밀 오답 ≤3 / 분투 오답 ≥4

| | 정밀 | 분투 |
|---|---|---|
| 높음 | ① 공명(共鳴) | ② 우직한 동행 |
| 중간 | ③ 냉철한 등반가 | ④ 무명(無名)의 등정 |
| 낮음 | ⑤ 고독한 해결사 | ⑥ 홀로 오른 탑 |

- 업적: **무결**(전층 무오답) · **침묵의 등반**(힌트 0)
- 고신뢰(≥80) → 총점 +20(G4)로 "검증하며 오른 길" 보상

## 설계 의도

- "맹신 말고 검증" 테마가 **엔딩까지 관통**: 라온에 휘둘리면 신뢰도↓ → 낮음 엔딩, 증거로 검증하면 높음 엔딩.
- plan.md "층 분기"는 랜덤 출제(X3)와 충돌 → **후속 확장**으로 분리(솔직 명시).
