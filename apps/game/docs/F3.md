- 작성일: 2026-11-19
- 상태: **FE 구현 · 통합 검증 대기** (태스크 전체 완료 아님)
- 기준: [tasks](../tasks.md), [FE 진행 현황](./FE-progress.md), [API 연동 제안](./FE-api-contract.md)

## 작업 내용
새 플레이 화면은 서버 problem/evidence/step을 바인딩한다. 기존 세 문제 목업은 기존 데모에 보존했다.

## 사용 매뉴얼
새 플레이 화면에서 서버가 배정한 문제 제목·목표·증거를 읽는다. 문제를 임의 선택하지 않는다.

## 동작 설명
문제 ID·층·유형에 따라 동일한 컴포넌트를 재사용한다. 공개 데이터에 correct, isTrap, requiredIds, 명령 스크립트를 요구하지 않는다.
