## 1. 결과 요약

등반 전체(시드·출제 순서·층·점수·신뢰도·진행)를 SQLite에 저장한다. 서버를 재시작해도 `GET runs/:runId`로 같은 상태가 복원된다.

## 2. 상세

- [game_store.py](../../../tools/vulnscan/game_store.py): `runs`(JSON), `creates`(requestId→runId, 생성 중복 방지), `ranks`.
- 기본 경로 `tools/vulnscan/data/game.db`(`.gitignore` 처리), `scanner.py --game-db <경로>`로 변경.
- 등반은 최근 1000개만 유지한다(랭킹 기록은 남는다).

## 3. 검증

`test_game_store.py`: 재시작 후 상태 동일·같은 create requestId는 같은 등반·복원 후 이어서 진행. 실제 서버를 `curl`로 재시작하며 시드·힌트 수가 유지됨을 확인.

## 4. 남은 것·참고

- `shortcut:` 등반을 JSON 한 덩어리로 저장한다. 동시 접속·집계 질의가 늘면 컬럼으로 분리한다.
- 오래된 등반 정리 기준은 개수뿐이며 만료 시간은 없다.
