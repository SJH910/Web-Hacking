## 결과 요약

1층 「기록 보관소」를 **터미널 탐색까지 구현 가능한 수준**으로 명세했다.

- **학습 주제:** 접근 로그 분석 → 무차별 대입 흔적 + 실패 미기록 (OWASP A07·A09)
  - 우리 진단 프로젝트의 실제 랩 취약점(B4 `limited_login` 죽은 코드)과 동일 소재
- **합성 데이터 3종:** `access.log`(6초 23회 실패→성공) · `security.log`(성공만 기록) · `gate.conf`(잠금 미설정)
- **허용 명령 9개:** `grep 401`·`count 10.0.0.9`·`cat security.log`·`diff attempts logged` 등 (화이트리스트 밖 안전 차단)
- **증거 3개:** E01 반복 시도 · E02 실패 뒤 성공 · E03 미기록 (+ 획득 경로)
- **완료 조건:** 행동(핵심 명령 실행) + 3단 결론 판정
- **3단 판정:** 분류→취약→조치, 보기·정답·**함정 보기**·해설
- **라온 대사:** 틀린 첫마디 + 단계별 힌트 3 (함정 첫마디 = 분류 오답 보기)
- **구현용 데이터 블록:** 계약 §8 형식 TS 객체 (백엔드 B1·B2가 그대로 사용)
