## 작업 내용

## 사용 매뉴얼

## 동작 설명
서버가 정한 seed/floor/problem을 사용한다. 층 또는 runId 변경 시 명령 기록·증거 선택·판정 선택을 초기화한다. 시드별 출제 알고리즘을 FE에 복제하지 않는다.
