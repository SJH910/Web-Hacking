# G7 — 층 전이·엔딩 분기

- 담당: 게임 기획 (황선정)

- 목적: 10층 등반의 **흐름과 엔딩 분기** 확정.

---

## 1. 층 전이

- **선형 10층.** 각 층 통과(3단 판정 정답) → 다음 층 해금. 통과마다 **세이브**(FloorState).
- 재시도형: 오답은 점수·신뢰도만 깎고 **실패(게임오버) 없음** → 누구나 완주 가능.
- 10층 통과 시 **엔딩 판정**(§3) → 랭킹 등록.

## 2. 분기 모델 (MVP 범위)

plan.md의 "선택에 따라 다음 층과 엔딩이 분기"를 두 갈래로 나눈다.

- **MVP: 엔딩 분기** — 문제 정답은 결정적이므로, 분기는 **누적 성과**(최종 신뢰도·정확도)로 발현. 서사적 "선택"은 **라온을 믿을지(함정 보기) vs 증거로 검증할지**의 매 판정이 쌓여 엔딩을 가른다.
- **후속(확장): 층 분기** — 특정 층에서 경로 선택지로 **다음 층 풀 subset**을 바꾸는 구조. 랜덤 출제(X3)와 충돌이 있어 별도 설계로 미룬다.

## 3. 엔딩 분기 — 두 축

10층 통과 시, 두 지표로 6개 엔딩을 가른다.

- **축1 · 최종 신뢰도(라온 관계):** 높음 `≥80` / 중간 `40~79` / 낮음 `<40`
- **축2 · 정확도:** 정밀 `총 오답 ≤ 3` / 분투 `총 오답 ≥ 4` (10층·30단계 기준)

| 신뢰도 \ 정확도 | 정밀(오답 ≤3) | 분투(오답 ≥4) |
|---|---|---|
| **높음 ≥80** | ① 공명(共鳴) | ② 우직한 동행 |
| **중간 40~79** | ③ 냉철한 등반가 | ④ 무명(無名)의 등정 |
| **낮음 <40** | ⑤ 고독한 해결사 | ⑥ 홀로 오른 탑 |

> 신뢰도 ≥80이면 **총점 +20**(G4) → "라온과 검증하며 오른" 길이 점수로도 보상된다.

## 4. 엔딩 서사·칭호

| # | 칭호 | 조건 | 한 줄 |
|---|---|---|---|
| ① | **공명(共鳴)** | 높음·정밀 | 라온이 틀릴 때마다 너는 증거로 바로잡았고, 라온은 조금씩 너를 닮아갔다. 맹신도 고립도 아닌 가장 어려운 길 — **의심과 믿음을 같은 손에 쥔 자**만이 이 정상에 선다. |
| ② | **우직한 동행** | 높음·분투 | 매 층 비틀거렸다. 확신 없이 고른 답은 몇 번이고 어긋났지만, 그때마다 라온이 먼저 손을 내밀었고 너는 그 손을 **증거로 되잡았다.** 빠르지도, 완벽하지도 않았다 — 그러나 **넘어진 자리마다 둘의 거리는 한 뼘씩 좁아졌다.** 서툴러도 끝까지 곁을 지킨, 우직한 등반이었다. |
| ③ | **냉철한 등반가** | 중간·정밀 | 증거만 믿고 한 걸음씩. 라온의 말은 참고였을 뿐, 판단은 끝까지 네 몫이었다. |
| ④ | **무명(無名)의 등정** | 중간·분투 | 요란한 묘수도, 단번의 정답도 없었다. 틀리면 다시 서고 막히면 돌아온 **이름 없는 발걸음** — 그러나 탑은 끝내 올라선 자를 묻지 않는다. 누구였는지가 아니라, **끝까지 올랐다는 것만이 남는다.** |
| ⑤ | **고독한 해결사** | 낮음·정밀 | 라온을 믿지 않았다. 그럼에도 틀리지 않았다. 외롭지만 날카로운 등반. |
| ⑥ | **홀로 오른 탑** | 낮음·분투 | 라온의 말에 휘둘리다 멀어졌고, 힘겹게 혼자 올랐다. 다음엔 증거를 먼저 보게 될까. |

### 업적(엔딩에 덧붙음)
- **무결(無缺):** 전 층 **무오답**(총 오답 0) → 엔딩 칭호에 추가. "열 개의 문을 단 한 번의 실수도 없이."
- **침묵의 등반:** 힌트 0회 사용.

## 5. 엔딩 화면 구성

- 칭호 + 서사 1~2줄
- 최종 지표: 총점 · 최종 신뢰도 · 총 오답 · 힌트 수 · (고신뢰 보너스 표기)
- 랭킹 등록(점수·신뢰도) + 순위 노출
- 다시 도전(새 시드 → 다른 10문제)

## 6. 구현 로직 (의사코드 · 상수)

```ts
function decideEnding(finalTrust: number, totalWrong: number, totalHints: number) {
  const trustTier = finalTrust >= 80 ? "high" : finalTrust >= 40 ? "mid" : "low";
  const skill = totalWrong <= 3 ? "precise" : "struggle";
  const ending = ENDINGS[trustTier][skill];           // ①~⑥
  const badges = [];
  if (totalWrong === 0) badges.push("무결");
  if (totalHints === 0) badges.push("침묵의 등반");
  return { ending, badges };
}
const ENDING_THRESH = { trust: { high: 80, mid: 40 }, preciseMaxWrong: 3 };
```
