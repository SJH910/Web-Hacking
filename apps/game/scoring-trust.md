## 1. 점수 (Score) — 랭킹 기준

한 층 = 3단 판정(분류→판정→조치). 각 단계는 정답까지 재시도 가능.

### 단계 기본점 (난이도별 · 단계당 만점)
| 난이도 | 단계 기본점 | 층 만점(3단) |
|---|---|---|
| 쉬움 | 10 | 30 |
| 보통 | 15 | 45 |
| 어려움 | 20 | 60 |

→ 어려운 문제일수록 점수가 커서, **후반 어려움 가중(9~10층)이 고득점 구간**이 된다.

### 감점·보너스
- **단계 오답:** 해당 단계 1회당 **−5** (단계 점수 하한 **2**)
- **힌트 사용:** 1단계당 **−3** (층 점수에서)
- **클린 클리어:** 그 층을 **무오답·무힌트**로 통과 시 **+5**
- 층 점수 하한 **0**

### 계산식
```
단계점 = max(2, 기본점 − 오답횟수×5)
층 점수 = Σ 단계점 − (힌트 수 × 3) + (무오답·무힌트면 5)   // 하한 0
총점   = Σ 10개 층 점수   → 랭킹 기준
```

**양호·증거 부족(needs_review) 문제도 동일** — 올바른 판정이 정답이면 만점 처리.

## 2. 신뢰도 (Trust · 라온)

- **시작 60**, 범위 **0~100**
- plan.md: "신뢰도에 따라 도움의 정확도가 변한다" → **신뢰도가 힌트 품질을 좌우**

### 증감
| 상황 | 신뢰도 |
|---|---|
| 단계를 **무오답으로** 정답(스스로 증거 검증) | **+2** |
| **라온 함정 보기 선택**(라온 말 그대로 추종) | **−5** |
| 그 외 오답 | **−2** |
| 힌트 사용(라온에 질문) | **−1/힌트** |

> 핵심: **라온에 휘둘리면 신뢰도가 크게 깎이고(−5)**, **증거로 스스로 맞히면 오른다(+2)**. "맹신 말고 검증" 테마를 수치로.

### 신뢰도 구간 → 힌트 품질
| 구간 | 라온 힌트 |
|---|---|
| 80~100 (두터움) | 3단계 모두 명확·정확 |
| 50~79 (보통) | 2단계부터 명확, 1단계는 모호 |
| 0~49 (소원함) | 자주 모호/빗나감, 스스로 풀어야 |

## 3. 게임 종료 보정

- **최종 신뢰도 ≥ 80:** 총점 **+20**("자력 검증" 보상)
- **최종 신뢰도 < 40:** 보너스 없음 + 엔딩 분기(홀로 오른 탑) — G7과 연결
- 엔딩 분기 상세는 **G7**(다음 층·엔딩).

## 4. 랭킹

- 1순위: **총점**
- 동점 시: **최종 신뢰도** 높은 순 → 그래도 같으면 **힌트 적게 쓴 순**
- 서버가 점수·신뢰도 저장·집계(B5·B6). 시드로 **같은 10문제**를 받으므로 공정.

## 5. 예시 (보통 난이도 한 층)

- 3단 전부 **무오답·무힌트**: 15×3 + 5 = **50점**, 신뢰도 +6
- 1단계에서 **함정 1회→정답**, 나머지 무오답: (10 + 15 + 15) − 0 + 0 = **40점**, 신뢰도 −5+2+2 = **−1**
- 힌트 2개 쓰고 다 정답: 45 − 6 = **39점**, 신뢰도 +6 −2(힌트) = +4

## 6. 구현용 상수 (B2가 사용)

```ts
const SCORE = {
  stepBase: { 쉬움: 10, 보통: 15, 어려움: 20 },
  wrongStepPenalty: 5,   // 단계 오답 1회당
  stepMin: 2,            // 단계 점수 하한
  hintPenalty: 3,        // 힌트 1개당(층 점수)
  cleanBonus: 5,         // 무오답·무힌트 통과
  floorMin: 0,
};
const TRUST = {
  start: 60, min: 0, max: 100,
  cleanCorrect: +2,      // 무오답 정답
  trap: -5,              // 라온 함정 보기
  wrong: -2,             // 그 외 오답
  hint: -1,              // 힌트 1개당
  // 구간→힌트 품질
  tiers: [{ gte: 80, hint: "clear" }, { gte: 50, hint: "mixed" }, { gte: 0, hint: "weak" }],
  endBonusHighTrust: 20, // 최종 ≥80 시 총점 가산
};
```
