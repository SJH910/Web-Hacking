## H1. 되돌아온 편지 — terminal · 어려움 · A01 SSRF · 취약

- 소재: 문이 "입력한 주소로 대신 심부름"을 간다. 내부 주소를 넣으면?
- 명령·출력:
  - `fetch http://example.test` → 정상 외부 응답
  - `fetch http://10.0.0.1/admin` → **내부망 응답 반환**(차단 없음)
  - `cat embed.conf` → `allowlist: none`
- 증거: E1 입력 URL로 서버가 대신 요청 · E2 내부 주소(10.0.0.1)도 요청됨 · E3 allowlist 없음
- 판정: ①A01(SSRF) ✅(함정: A05 인젝션) ②취약 ✅ ③대상 allowlist·내부/메타데이터 차단 ✅
- 라온(틀림): "주소 넣으면 보여주는 편한 기능이지." → 분류 함정
- 어려움 이유: "정상 외부 fetch"와 **SSRF를 구분**해야 함
- flag: `FLAG{floor_ssrf}`

## H2. 두 얼굴의 토큰 — terminal · 어려움 · A08 무결성(토큰 서명) · 취약

- 소재: 로그인 토큰이 위조 가능한지 뜯어본다.
- 명령·출력:
  - `decode token` → `{ alg:"none", role:"user" }` (서명 없음)
  - `edit token role=admin` → **서버가 그대로 수락**
  - `cat token.conf` → `verify_signature = false`
- 증거: E1 토큰 alg=none(서명 없음) · E2 role 바꿔도 수락 · E3 서명 검증 꺼짐
- 판정: ①A08 무결성 ✅(함정: A07 인증) ②취약 ✅ ③서명 검증 강제·alg 고정 ✅
- 라온(틀림): "토큰 있으면 로그인된 거니까 괜찮아." → 분류 함정(인증과 혼동)
- 어려움 이유: 토큰 구조 해독 + **무결성 vs 인증** 구분
- flag: `FLAG{floor_unsigned_token}`

## H3. 느린 자백 — terminal · 어려움 · A05 시간 기반 블라인드 SQLi · 취약

> 화면 출력엔 **차이가 없고**, 응답 "시간"만 다르다. 가장 미묘.

- 소재: 내용은 같은데 주입에 따라 지연이 생긴다.
- 명령·출력:
  - `probe 1` → `0.02s`
  - `probe 1 AND sleep(3)` → `3.01s`
  - `probe 1 AND sleep(0)` → `0.02s`
- 증거: E1 출력은 항상 동일(블라인드) · E2 sleep(3) 주입 시 3초 지연 · E3 지연이 입력에 좌우됨
- 판정: ①A05(블라인드 SQLi) ✅(함정: 서버 부하/느림) ②취약 ✅ ③파라미터 바인딩 ✅
- 라온(틀림): "그냥 서버가 좀 느린 거 아냐?" → 분류 함정(부하)
- 어려움 이유: 내용 차이 없이 **시간**으로만 판정
- flag: `FLAG{floor_time_based_sqli}`

## H4. 멀쩡해 보이는 문 — terminal · 어려움 · A04 암호화(민감정보) · 취약

> 증거 대부분이 "양호"를 가리킨다. **성급히 양호로 찍으면 오답.** 강한 함정.

- 소재: 겉(전송·헤더)은 완벽한데 한 곳이 샌다.
- 명령·출력:
  - `headers /pay` → `HTTPS ✓  CSP ✓  HSTS ✓  Set-Cookie: sid=…; Secure; HttpOnly` (다 좋아 보임)
  - `cat /pay body` → **응답 본문에 카드번호 전체 평문**
  - `cat storage.conf` → `card_number: stored plaintext`
- 증거: E1 전송·헤더는 양호 · E2 응답·저장에 카드번호 평문 · E3 민감정보 평문 저장
- 판정: ①A04 암호화 ✅ ②취약 ✅(함정: 양호 — 겉만 보면) ③민감정보 마스킹·암호화 저장 ✅
- 라온(틀림): "HTTPS에 헤더까지 완벽한데? 양호지." → **강한 판정 함정**
- 어려움 이유: 다수 증거가 양호를 가리키고 **한 증거가 결정적** — 전체를 끝까지 봐야 함
- flag: `FLAG{floor_sensitive_plaintext_storage}`
