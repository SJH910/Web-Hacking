# 게임 FE와 vulnscan 메뉴 통합

- 일자: 2026-11-18
- 기준: `feat/integrate-game`의 `d29fb6e` 및 로컬 `hsj` FE
- 결과: vulnscan 상단 우측 게임 메뉴 → 같은 서버의 `/game/` 정적 게임 화면

## 변경과 범위

pull된 `apps/game`은 이전 488줄 화면 목업이었다. 로컬 hsj의 밝은 대시보드, 시나리오별 증거, 선택·판정, 실행·오류·완료 상태를 반영했다. 새 기획 문서 `floor-slice-design.md`, `tasks.md`는 변경하지 않았다.

현재 게임은 기존 제3층 데모이며, 기획에서 확정된 1층 순차 진행·서버 판정·터미널 탐색·랭킹 구현 완료를 뜻하지 않는다. 기획의 시나리오와 데이터 계약을 이 FE 목업 데이터로 대체하지 않는다. 화면과 실행 안내에 FE 데모임을 표시했다.

Next.js를 `/game` 경로로 정적 내보내고, vulnscan이 빌드 파일만 제공한다. 메뉴 전환 때 iframe을 유지해 게임 진행과 스캐너 화면 상태를 보존한다. 원본 hsj 폴더는 수정하지 않았다. 인트로 Link 경로와 BGM 파일 경로도 `/game/`에서 동작한다.

## 검증 결과

- Next.js 프로덕션 정적 빌드 및 TypeScript 검사 통과.
- 게임 판정 테스트 7개 통과.
- Python 게임 경로 테스트 7개 통과: 기존 대시보드, 리다이렉트, 게임/인트로, CSS MIME, 상위 경로·외부 심볼릭 링크 차단, 없는 파일, 빌드 누락.
- 게임·인트로 HTML과 연결된 리소스 경로 15개 HTTP 200. 기존 `/api/defaults` 응답 확인.
- 대시보드 인라인 JavaScript 구문 검사 통과.
- 브라우저에서 우측 게임 메뉴, 조사 로딩, 증거 두 개 선택 및 완료, 메뉴 왕복 후 진행도 유지, 인트로 진입·복귀 확인.
- 320px에서 발견한 게임 내부 가로 넘침 수정 후 내부 콘텐츠 폭과 화면 폭 일치 확인. 768px, 1024px, 1440px 화면도 점검.
- 브라우저 로그에 출처 URL 없는 MutationObserver 오류 1건이 관찰됐다. 앱 동작은 위 흐름으로 확인했으나 오류 발생 주체는 특정하지 못했다.
- 실제 스캔·외부 대상 요청·DB 변경·커밋·푸시는 수행하지 않았다.

게임은 빌드 결과이므로 소스 변경 시 재빌드가 필요하며, 전체 새로고침 후 게임 진행 영구 저장은 아직 없다.
