# [태스크 번호] 태스크 이름 — 완료

- 담당: (W / S1 / S2 / 전원)
- 완료일: YYYY-MM-DD
- 상태: (완료 / 일부 완료 + 남은 것)
- 관련 이슈·커밋: (#번호, 커밋 해시)

---

## 1. 결과 요약

무엇을 했는지 2~3문장. 표가 편하면 표로.

## 2. 상세

- 진단 태스크: 대상 기능, OWASP 항목, 재현 절차, 영향도(CVSS), 권고 조치, PoC 위치
- 구현·조치 태스크: 만든 기능, 넣은(또는 고친) 취약점, 변경 파일

## 3. 검증

- 확인한 방법과 결과 (PoC 재실행 결과, 스캔 비교 등)

## 4. 남은 것·참고

- 다음 태스크로 넘길 내용, 범위에서 뺀 것과 이유
