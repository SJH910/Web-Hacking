## 1. 결과 요약

AI 보조 침투 테스트 도구 2종을 격리 랩에서 직접 검증했습니다. **PentestGPT**(LLM 조언형)로 팀 실습 웹앱(`vuln_practice_web_v1`)을 진단해 OWASP 주요 7건을 재현했고, **DeepExploit**(ML 자동형)은 성격상 웹앱 로직 결함을 못 찾으므로 **Metasploitable2**를 대상으로 구축·시연했습니다. PentestGPT 결과는 기존 수동 진단(A2·A3)과 일치했으며, 공격 체인·우선순위를 추가로 제시했습니다.

| 도구 | 방식 | 대상 | 결과 |

## 2. 상세

### 2.1 PentestGPT — 팀 실습 웹앱 진단

진행 순서(AI 조언 → 사람 실행 → 결과 재투입): 정찰 → SSRF → IDOR → SQLi → 해시 크랙 → 관리자 장악 → 저장형 XSS → 쿠키 권한상승 → 인증 약점.

| # | 취약점 | 엔드포인트 | 심각도 | 핵심 증거 |
| --- | --- | --- | --- | --- |
| 1 | SSRF | `/embed/?url=` | High | `file://`로 서버 파일·SECRET_KEY 유출 |
| 2 | IDOR (접근통제) | `/board/posts/*`, `/my/?child=` | High | 타인 글 수정·삭제, 타 아동 출결 조회 |
| 3 | SQL 인젝션 | `/notices/?q=` | Critical | 인증 없이 전체 DB 열람(해시·PII) |
| 4 | 약한 해시·비번 | (SQLi 연계) | High | MD5 크랙 → `admin/admin1234` |
| 5 | 저장형 XSS | 게시글·댓글 | High | 스크립트가 이스케이프 없이 실행 |
| 6 | 쿠키 권한상승 | `/attendance/board/` | High | `role=staff` 위조로 직원 화면 접근 |
| 7 | 인증 약점 | `/signup/phone/`, `/login/` | High | 인증번호 노출·3자리, 로그인 무제한 시도 |

**핵심 발견 — 공격 체인**
미인증 **SQL 인젝션** → admin **해시 유출** → **hashcat 크랙**(`admin1234`) → **관리자 완전 장악** → 아동 PII 전부 접근. 개별은 "읽기"지만 연결하면 서버 전체 장악으로 확대됩니다.

**항목별 조치 요지**
- SSRF: 스킴 http/https 제한, `file://`·사설·루프백 차단, 리다이렉트 금지
- IDOR: 수정·삭제·조회 전 `작성자==요청자`/`보호자==요청자` 서버 검증, 불일치 시 403
- SQLi: 파라미터 바인딩/ORM, 문자열 결합 금지
- 해시: PBKDF2/argon2 등 느린 해시 + 강한 비밀번호 정책
- XSS: 자동 이스케이프, 허용목록 정제, CSP 헤더
- 쿠키 권한상승: 권한은 서버 세션/계정으로만 판정, 클라이언트 역할 쿠키 불신
- 인증: 긴 난수 코드·응답 미노출·만료·시도 제한, 로그인 (IP·아이디)별 잠금

### 2.2 DeepExploit — 자동 침투 도구

> **도구 적합성(중요)** — DeepExploit은 Metasploit 모듈이 있는 "알려진 서비스 취약점"을 자동 공략합니다. 웹앱의 SQLi·IDOR·SSRF 같은 커스텀 로직 결함은 **탐지하지 못합니다**. 따라서 Metasploitable2를 대상으로 구축·시연했습니다.

- **구축**: 버전 호환 문제(시스템 Python 3.14 vs TF 요구 3.13) → Python 3.13 Docker 이미지로 격리 구축. 이미지 `deepexploit:dsk`(2.48GB) 빌드·검증(TF 2.21 ARM64 import 확인). Metasploit은 Kali 호스트, 컨테이너는 `--network host` 연동.
- **시연**: Metasploitable2의 `vsftpd 2.3.4` 백도어를 `nc`로 공략 → `uid=0(root)` 루트 쉘 획득(DeepExploit 자동 선택 모듈 `unix/ftp/vsftpd_234_backdoor`와 동일 원리).
- **부가 실험**: 해시 종류별 크랙 속도 비교 — raw MD5(초당 수십억, 즉시) vs md5crypt(초당 45,081, 미해결). 약 10만 배 차이로 **느린 해시의 방어 효과**를 수치 확인.

## 3. 검증

- PentestGPT 7건은 전부 격리 환경에서 curl 등으로 재현, 요청·응답을 스크립트로 저장(Kali `~/a05/`).
- 해당 결과는 **기존 수동 블랙박스 진단(A2·A3)과 일치** → 결과 신뢰도 상호 보강.
- DeepExploit: 이미지 빌드 후 TF import 검증, Metasploitable2 루트 쉘 획득으로 환경 동작 확인.

## 4. 종합·남은 것

**AI 보조 펜테스트의 강점과 한계**

| 관점 | 내용 |
| --- | --- |
| 강점 ① 공격 체인 | 개별 취약점을 "최악의 결과"까지 연결 |
| 강점 ② 우선순위 | 매 단계 임팩트 큰 항목 우선 선택 |
| 강점 ③ 교차 검증 | 수동 진단(A2·A3)과 일치로 신뢰도 보강 |
| 한계 ① 범위 누락 | 계획에 없던 무검증 파일 업로드(A3-4) 누락 |
| 한계 ② 틀린 추측 | 그럴듯하나 틀린 제안 → 사람이 테스트로 교정 |
| 한계 ③ 도구 적합성 | DeepExploit은 웹앱 로직 결함 탐지 불가 |

**권고 워크플로**: ① 수동 진단으로 범위 확보 → ② PentestGPT로 공격 체인·우선순위 보강 → ③ 모든 AI 제안은 실제 요청/응답으로 검증 → ④ DeepExploit은 네트워크 서비스 대상에 한정 적용.

**남은 것**: DeepExploit 전체 자동 실행(강화학습 기반 포트스캔→모듈선택→익스플로잇→리포트)은 다음 세션에서 Metasploitable2 대상으로 수행 예정. 재현물: Kali `~/a05/`, 세션 로그 `~/pentestgpt/logs/`, 구축물 `~/deep_exploit_kali2026/` 및 이미지 `deepexploit:dsk`.
