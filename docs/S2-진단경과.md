- 취약점 미발견(A03)도 유효한 진단 결과로 기록한다.

## 4. 진행 방식

- **블랙박스 우선:** 진단 중 취약판 소스를 열지 않고 스캐너·수동 재현으로 외부에서 탐지. 의존성 목록은 스캔 입력이라 예외.
- **안전 범위 통제:** 능동 스캔은 W가 전달한 제외 경로(로그아웃·계정 생성·데이터 삭제·외부 요청) 밖만 공격해 데이터 변경·외부 요청을 일으키지 않음.
- **자동 + 수동 병행:** ZAP이 놓친 항목(DEBUG 노출)을 수동 재현으로 보완하고, 자동 판정을 수동으로 재확인.
